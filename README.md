# Procesos y Servicios

Este repositorio reúne programas y prácticas orientados a la programación de 
procesos y servicios

## 📁 Contenido

El código (`src/`) se encuentra organizado por:

- **Protocolos y entornos Web:**
  - Uso del objeto `InetAddress` y sus métodos .
  - Manipulación de objetos `URL` y `URLConnection`
  - Pruebas y scripts con `PHP`.
- **Sockets TCP (Cliente-Servidor):**
  - Conexiones orientadas a flujo mediante `Socket`, `ServerSocket`, `DataInputStream` y `DataOutputStream`
- **Sockets UDP (Cliente-Servidor):**
  - Comunicación mediante datagramas con `DatagramSocket` y `DatagramPacket`
